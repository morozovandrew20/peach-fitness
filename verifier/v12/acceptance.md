# PEACH v12 — Релиз 1.2 «Практика вместо доказательной базы»

## Запрос владельца
Убрать из интерфейса оценки «слабо/средне/сильно доказано» и разборы исследований. Объяснять практично: упражнения дополняют друг друга по точкам амплитуды, число подходов оптимально для роста (больше не нужно), волна даёт предсказуемый прогресс без ручных таблиц.

## Решения
- `exerciseWhy`: только «Что работает» и «Зачем в программе», без оценок и исследований; тот же блок используется в диалоге техники.
- Настройки: «На чём это основано» заменено на «Почему план именно такой» — амплитуда, оптимальный объём, волна. Константа BASIS удалена.
- Альтернативам «Жим ногами» и «Сгибание ног лёжа» добавлены практичные описания.
- Исследования остаются на `credits.html`. Логика, данные и 3D не менялись. Кэш `peach-flagship-15`.

- static: хэши анимации = v9, отсутствие evidence UI, практические тексты, кэш 15.

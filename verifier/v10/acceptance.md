# PEACH Релиз 1.0 (v10) — релизная упаковка

## Принцип
Анимация и логика тренировок не переписывались. Все файлы техники
(`technique.js`, `technique3d.js`, `peach-mannequin.glb`, лицензии, `technique3d.src.js`)
байт-в-байт совпадают с тегом `flagship-ui-v9` (проверяется по SHA-256).

## Продуктовый результат
- Метаданные релиза: title/description/canonical/og/twitter для публикации и шеринга.
- Welcome-экран: строка ключевых возможностей (Релиз 1.0 · 3D-техника · Офлайн · Без аккаунта).
- Карточка релиза на экране настройки со ссылками: что нового, конфиденциальность, условия, источники, поддержка.
- Юридические страницы: `privacy.html`, `terms.html`, `credits.html`, `release.html` — валидная разметка, favicon, честные формулировки без медицинских обещаний.
- PWA: манифесты (светлый/тёмный) с описанием, категориями, скриншотами; `favicon.ico`; кэш Service Worker `peach-flagship-13` со всеми новыми файлами.
- Скриншоты для установки: `assets/release/screenshot-mobile.png`, `screenshot-progress.png` (390×844).

## Проверка
- Статика: хэши анимации = v9, синтаксис JS, манифесты JSON, состав SW core, наличие всех новых файлов, лицензии MIT.
- Browser (release): welcome-строка, карточка релиза и 5 рабочих ссылок, доки отдают 200 и PEACH, манифест валиден, install prompt, одна 3D-сцена доходит до кадров (интеграционное доказательство), 360/390/768/1440, light/dark, zero console errors/404.
- Browser (full): полный регресс v9 — все восемь упражнений, live, resilience, offline reload, core assets 200.
- Всё локально и на GitHub Pages; каждый запуск в `verifier/runs/`; предыдущие verifier/v* неизменны.
- Отдельный протокольный коммит и release tag `release-1.0.0` после успешной публикации.

# PEACH v9 — фирменная интерактивная 3D-техника

## Продуктовый результат
- Все восемь основных упражнений имеют собственное узнаваемое 3D-движение: `ht`, `rdl`, `bulg`, `abd`, `sq`, `hyper`, `kick`, `curl`.
- Движения соответствуют инструкциям PEACH: штанга и скамья в мосте, таз назад в тяге, задняя нога на скамье в болгарском, валики в отведении, платформа и опора в гакке, скруглённый корпус в гиперэкстензии, нижний блок в кикбэке, сидячее сгибание ног в тренажёре.
- Никаких подмен: bodyweight squat не выдаётся за гакк, мах ногой — за кроссовер, ягодичный мост без штанги — за мост со штангой.
- Единый премиальный визуальный язык: светлый скульптурный манекен, графитовые сочленения, персиковые акценты, мягкая студийная сцена, контактные тени, читаемое оборудование и крупный силуэт на мобильном.

## Взаимодействие и доступность
- Реальные WebGL-кадры, а не видео/GIF; работают пауза/продолжение, скорость 0,5×/1×, ракурсы и вращение жестом/мышью.
- Есть DOM-альтернатива всем действиям, доступные названия и видимый keyboard focus; диалог по-прежнему закрывается.
- `prefers-reduced-motion` запускает статичный информативный кадр; автовоспроизведение возобновляется только по явному действию.
- При скрытии диалога/вкладки рендер останавливается. Ошибка WebGL/загрузки показывает прежнюю локальную SVG-схему без пустого/чёрного canvas.
- Текст инструкций, настройка, ошибки и остальной `info` dialog сохранены.

## Производительность и офлайн
- Все runtime-библиотеки, модель и шрифты локальные; во время работы техники нет сторонних сетевых запросов.
- Модель оптимизирована; целевой бюджет сцены — до 30 000 треугольников и до 45 draw calls, DPR ограничен для мобильных.
- Новые файлы входят в Service Worker core; повторный offline reload и открытие каждой техники работают.
- Сохраняются оригинальный логотип, `volny-v1`, формулы, таймеры, сессии, backups, экспорт и весь v8 regression.

## Проверка и публикация
- Статические проверки восьми clips/сцен, лицензий, offline core и отсутствия внешних runtime URL.
- Browser: все восемь упражнений, реальное изменение кадров, controls, reduced motion, fallback, dialog return, 360/390/768/1440, light/dark, zero console errors/404.
- Скриншоты ключевых поз просмотрены; найденные визуальные дефекты исправлены и перепроверены.
- Полный v8/v7 регресс локально и на GitHub Pages, реальный offline, все core assets HTTP 200.
- Каждый запуск сохраняется в `verifier/runs/`; предыдущие verifier/v* неизменны. Отдельный протокол и release tag после успешной публикации.

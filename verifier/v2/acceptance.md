# PEACH flagship acceptance v2

Дата: 2026-11-25. Наследует все критерии v1 и добавляет проверку новых продуктовых сценариев.

1. Первый запуск начинается с заголовка «Выбери уровень»; уровень «Новичок» проводит в тренировку без внешних ресурсов.
2. Первый подход записывается через штатный редактор, сохраняется в `volny-v1` и остаётся после перезагрузки.
3. Техника открывается из карточки упражнения, содержит SVG и текст; диалог закрывается клавишей Escape.
4. Прогресс после одного подхода показывает обзор блока, 12 недель и один записанный подход; пустое состояние содержит понятный CTA.
5. Завершённая тренировка показывает итоговую карточку и bottom sheet без потери записей.
6. Светлая и тёмная темы не имеют горизонтального overflow на 360 px; desktop 1440 px сохраняет читаемую колонку и рабочую навигацию.
7. Клавиатурный фокус видим; reduced motion поддерживается; все интерактивные элементы сохраняют доступные имена.
8. После установки Service Worker приложение перезагружается офлайн; core assets находятся в актуальном cache `peach-flagship-5`.
9. Нет необработанных ошибок console и неожиданных first-party request failures.
10. Публичный GitHub Pages повторяет локальный smoke test; публичные `index.html`, `flagship.css`, `technique.js`, `sw.js` и шрифты возвращаются как реальные файлы, не base64-текст.
11. Существующие записи, заметки, настройки, программа и расчёты не изменяются миграцией; тест выполняется только в изолированном браузерном профиле.

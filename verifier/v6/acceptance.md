# PEACH release-product acceptance v6

Создано: 2026-11-25. Наследует v1–v5. Срез отвечает на повторную оценку «всё ещё бета»: устраняет структурную перегруженность, а не добавляет декоративный слой.

## Сценарная завершённость

1. Первый запуск при 360×800 не выглядит как длинная анкета: один компактный брендированный hero, заголовок «Выбери уровень» и все три варианта видимы без прокрутки; дублирующий `Начнём` скрыт только в welcome mode.
2. На первом и продолжаемом дне главный следующий шаг доступен в первом viewport: открыть первый/текущий подход одной кнопкой. Лёгкий день остаётся доступным, но не заменяет основной CTA.
3. Первичная инструкция по подбору веса использует progressive disclosure: суть доступна по summary, развёрнутый текст не отодвигает редактор и остальные упражнения на несколько экранов. Вся информация сохранена.
4. Настройки получают работающую навигацию по содержанию: «Программа», «В зале», «Данные». Переходы ведут к реальным разделам, учитывают sticky/fixed UI и не меняют состояние.
5. Основные экраны используют единый ритм: максимум один тёмный hero на экране, вторичные справки тонкие, одиночные ссылки не оформлены как тяжёлые карточки, заголовки не ломаются внутри слов.

## Визуальный release gate

6. Реальные viewport screenshots: welcome до/после выбора, первый день, продолжение дня, редактор, focus, rest, settings с навигацией, progress empty/filled, completion; light/dark; 320/360/390/768/1440.
7. Нет горизонтального overflow, clipping, случайного hyphenation, перекрытия CTA навигацией, незаполненных «пустых» областей и конкурирующих primary buttons.
8. Touch targets основных действий ≥48 px, focus trap/Escape/restore работают, reduced motion отключает необязательную анимацию, оригинальный `peach-logo.svg` загружается.
9. Все v5 functional/product-finish проверки проходят локально и публично; cache обновлён до `peach-flagship-9`; offline repeat reload и core assets HTTP 200 подтверждены.
10. Формат `volny-v1`, копии, выбор упражнений, формулы, прошлые записи и timers не меняются. Все новые controls имеют реальную реализацию.
